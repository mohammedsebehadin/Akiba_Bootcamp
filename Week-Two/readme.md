# Week Two Python Practice

This repository contains a collection of beginner-friendly Python exercises completed during Week Two of the AKIBA Bootcamp. The programs focus on core programming concepts such as loops, conditionals, arithmetic operations, input handling, and simple algorithmic logic.

## Included Programs

- `ATM_PIN.py` – Simulates a 4-digit ATM PIN check with limited attempts.
- `count_number.py` – Counts even and odd numbers and calculates their sum up to a given natural number.
- `evenOdd.py` – Checks whether a number is even or odd.
- `fizz_buzz.py` – Prints numbers from 1 to 100 with Fizz, Buzz, and FizzBuzz rules.
- `guessing_number.py` – A number guessing game with a limited number of attempts.
- `largest_smaller.py` – Compares three numbers and prints the largest one.
- `number_analayzer.py` – Analyzes ten entered numbers to determine sum, average, even/odd count, and largest/smallest values.
- `palindrome.py` – Checks whether a word or number is a palindrome.
- `prime_number.py` – Determines whether a number is prime.
- `sum_of_digits.py` – Adds the digits of a number.

## How to Run

Open a terminal in this folder and run any script with Python:

```bash
python3 ATM_PIN.py
```

Replace `ATM_PIN.py` with the file you want to run.

## Learning Goals

These exercises help build confidence in:

- Python syntax and basic input/output
- Conditional statements
- Loops and iteration
- Mathematical and logical problem solving
- Beginner algorithm design
